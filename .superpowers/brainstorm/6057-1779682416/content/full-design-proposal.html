Animation System
4 Signature Cinematic Techniques
GSAP + ScrollTrigger. Each used once — overuse kills the effect.
The Curtain Transition
Between Hero and About: a full-viewport gold panel drops from the top, holds 0.15s, then retracts as the next section fades in beneath. Film-cut feel. Used once only — between sections 1 and 2.
ScrollTrigger.pin()
Deck Peel
Membership tiers stack as a deck. Each card exits via translateY(-100%) while the next scales up from 0.88. Overlap of 0.2s creates seamless layering — like peeling back luxury stationery.
pin + scrub: 1
Text Slice Reveal
All major headlines: overflow:hidden parent. Text translateY(100%) into view — line by line, staggered 0.08s. Text travels, never fades. This distinction separates cinematic from amateur.
SplitText + stagger
Parallax Depth Layering
Three speed layers per section: 0.6x (bg glow), 1.0x (cards), 1.2x (eyebrow labels). Creates genuine depth — like looking through a lit window. No 3D transforms.
Multiple ScrollTriggers
Architecture
Technical Stack
Next.js 15 · Static export · Cloudflare Pages. Zero backend needed.
Next.js 15
Framework
App Router. Static export output: 'export'. No adapter needed for Cloudflare — just serve the out/ dir.
GSAP + ScrollTrigger
Animation
Timeline orchestration + scroll-pinning. gsap.context().revert() prevents React remount accumulation. Single import from src/lib/gsap.ts.
Lenis
Smooth Scroll
Cinematic inertia scrolling. Integrates natively with GSAP ScrollTrigger. Without it, scroll feels mechanical on Windows Chrome.
Tailwind CSS 3.4
Styling
Color tokens in theme.extend. Stable config model. Avoid Tailwind 4 — fewer plugins, new syntax, no upside here.
sharp
Image Pipeline
Pre-convert your 4 HEIC source images to WebP at 2400px + 1200px. Commit to public/images/optimized/. Static export can't use Next.js image server.
WhatsApp Deeplink
Primary CTA
Pre-filled message. One tap to booking. No form, no backend. India's highest-converting CTA pattern for local luxury services. Calendly as secondary for structured booking.
Content Gaps
Needed Before Launch
From Medhavi's analysis — these gaps cost bookings if left empty.
Working Hours
Not in brochure. Website needs: days open, first/last slot. Every booking decision depends on this.
Therapist Credentials
One line: training origin, years experience, number of therapists. Converts hesitant first-timers.
Privacy & Gender Policy
Is spa mixed-gender? Are sessions private rooms? Answering on-site removes a major unspoken objection.
Couple Sessions
Highest-demand service in Vizag (anniversary, honeymoon). High revenue unlock — if available, must be featured.
Gift Vouchers
"Gift a session of stillness" — a distinct offering path with WhatsApp inquire link activates the gifting segment.
Google Maps Navigation Note
4th floor, PNB Complex isn't obvious. Add landmark reference: "near Rushikonda junction, above [bank]".
